# Plans

One Markdown file per plan: `.claude/plans/<slug>.md`. Plan files are written in **English**.

Minimum template:

```markdown
# Title

## Goal
What we need to achieve.

## Context
Facts from the repo / dumps / emu.

## Steps
- [ ] ...

## Out of scope
...

## Done when
How we verify it.
```
