# General rules

## Git

- **Never commit, push, amend, or create a PR unless the user explicitly asks for that action.**
- Do not `git add` / `git commit` / `git push` as a side effect of other work.
- “Looks good” or “done” is not permission to commit.

## Language

- **All code, comments, docstrings, and identifiers must be in English.**
- Chat with the user may be in Spanish. Files that live in the repo (source, comments, commit messages if/when allowed) stay English.

## Scope

- Change only what was asked. No drive-by refactors.
- No empty TODOs or leftover commented-out code.
- If something is blocked (missing dump, emu, API), say so; do not fake it with a stub.
- Never put secrets or keys in the repo.
